# React + TypeScript + Vite

Este projeto foi desenvolvido para resolver a seguinte atividade:

**Descrição da atividade:** Desenvolver um aplicativo React com TypeScript contendo dois componentes.  
Este repositório contém a solução para a atividade proposta, que consiste em desenvolver um aplicativo React com TypeScript. O exercício envolve dois componentes principais:

- `Exercise1`: Solicita ao usuário a quantidade de números aleatórios a serem gerados, exibe-os em ordem crescente e limita a 12 números.
- `Exercise2`: Recebe números fornecidos pelo usuário, exibe no máximo 12 números e permite a remoção de números ao clicar com o botão direito.

O objetivo é compreender e utilizar componentes React, gerenciar dados com state e passar informações entre componentes usando props. Além disso, os números são exibidos em um componente chamado `Ball`, e os estilos foram implementados com CSS-in-JS.
